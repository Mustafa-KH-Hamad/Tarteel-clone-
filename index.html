      How it works

      Choose a surah, press Start and recite. Each word turns green when it is correct, red when it is wrong, and orange when you skip it. You can tap any word to start from there.

      Speech is recognised by your browser's built-in speech engine (Google Chrome works best), so an internet connection is needed. It checks words; it cannot judge tajweed, and it may sometimes mishear a word.

      Quran text: Uthmani script from The Noble Qur'an Encyclopedia (quranenc.com), translation Saheeh International, via the open quran-json dataset (CC BY-SA 4.0).
